# Conference demos

Demos presented at AWS conferences.

## Contents

- [re:Invent 2025 - WPS202: Resilience Agent](./re-Invent%202025/WPS202/Resilience_Agent/README.md) - A sample resilience agent built using the Strands Agents SDK. Demoed at 2025 AWS re:Invent in WPS202 - **Chaos & Continuity: Using Gen AI to improve humanitarian workload resilience** and AIM336 - **Using AI to improve humanitarian workload resilience**.
- [re:Invent 2026 - AIM330: Champagne AI on a beer budget: Cost-optimized AI architectures live](./re-Invent%202026/AIM330/Champagne_AI/README.md) - A surprise cloud bill can wipe out a nonprofit's budget, but running frontier-quality generative AI doesn't have to cost frontier prices. In this code talk, we build an architecture that gets premium model output on a fraction of the spend. 
- [re:Invent 2026 - AIM333: The Agent Harness: Unifying Fragmented Tools for Mission AI Advisors](./re-Invent%202026/AIM333/Agent_Harness_for_Mission_Advisors/README.md) - Advisors across mission-driven organizations—financial advisors, benefits navigators, program coordinators—juggle fragmented tools, manual research, and delayed plan delivery while clients go underserved. AI agents change this equation. See how to collapse this fragmentation into configuration using the Amazon Bedrock AgentCore Harness. 
- [re:Invent 2026 - AIM337: Four agents, one answer: multi-agent synthesis on AWS](./re-Invent%202026/AIM337/Multi_Agent_Synthesis/README.md) - Turning messy, unstructured sources into summaries you can trust takes more than one model. We walk through a working multi-agent system where four specialized agents (a searcher, an analyst, a verifier, and a synthesizer) collaborate to produce cited, evidence-backed results, each running on the Bedrock model best suited to its job.
