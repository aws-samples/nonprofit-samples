# Older examples

Earlier samples built on Amazon Bedrock and other AWS ML services. They remain useful as references.

## Amazon Bedrock

- [Meeting Summarization with Claude](./bedrock/Meeting_Summarization/README.md) - Uses generative AI to summarize a meeting recording.

- [Natural Language Query with Amazon Bedrock (React Single-Page Application)](./bedrock/Bedrock_NLQ_React_App/README.md) - Deploys a React single-page application (SPA) with the AWS Cloud Development Kit (CDK) that hosts a chatbot for natural language query of structured data.

- [Retrieval Augmented Generation (RAG) Chatbot](./bedrock/RAG_Chatbot/README.md) - Builds a simple chatbot that can respond to questions about your custom content.

## Machine learning

- [Using machine learning to customize your direct mailings](./ml/DirectMailing_With_Amazon_Personalize/README.md) - Sets up a personalization solution for a direct mailing workflow.

- [Social Media Sentiment](./ml/Social_Media_Sentiment/README.md) - Sets up a social media sentiment monitor. A nonprofit can gather sentiment on their handle and run analytics on the data gathered.

- [Targeted Messaging with Amazon Pinpoint and Amazon Personalize](./ml/Targeted_Messaging_With_Pinpoint_and_Personalize/README.md) - A POC-in-a-box showing how Amazon Personalize and Amazon Pinpoint work together to create targeted, personalized messages to an audience.
